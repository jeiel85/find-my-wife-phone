# 실기기 검증 체크리스트 (릴리스 전)

에뮬레이터로는 확인할 수 없는 것들입니다. 두 폰(A = 남편, B = 아내)에 `dist/find-my-wife-phone.apk`를 설치한 뒤 진행합니다.
소리가 나는 항목은 시간대를 고려하고, 가능하면 B 폰 알람 볼륨을 낮춘 상태에서 시작합니다(앱이 올렸다가 원래 값으로 되돌리는지 보는 게 목적).
진행 중 로그: `adb -s <B> logcat -s Hub RingService LocateService SoundState`

## 연결
- [ ] A·B 첫 실행 → 이름 입력 → 권한 화면에서 알림·잠금 화면 표시·방해 금지 접근·위치(항상 허용) 켜기. 배터리 최적화 제외(삼성).
- [ ] A **내 QR 보여주기**, B **QR 스캔하기** → 양쪽에 "연결됐어요", 홈 카드에 상대 이름·기기명·배터리 표시.
- [ ] 같은 QR을 다시 스캔하면 "이미 쓰였거나 없어요".

## 울리기 (B 화면 꺼짐·잠금 상태에서)
- [ ] A **울리기** → 수 초 안에 B 잠금 화면 위 카운트다운. A 단계 표시가 *확인 10초*로.
- [ ] B **거절하기** → A "거절했어요". 소리 없음.
- [ ] 다시 울리기 → 10초 뒤 **진동/무음 모드에서도** 울림, 4초에 걸쳐 커짐. A "울리는 중".
- [ ] B **찾았어요** → 소리 멈춤, A "찾았대요! 🎉". **B 알람 볼륨이 울리기 전 값으로** 돌아왔는지 확인.
- [ ] B **방해 금지 켠 상태**에서 울리기 → 울리는지, 끝난 뒤 방해 금지가 **다시 켜져 있는지**. (Android 15+ 암시적 규칙 동작 기록)
- [ ] 울리는 중 A **그만 울리기** → B 즉시 멈춤 + 복원.
- [ ] 울리는 중 B 폰 앱 강제 종료(`adb shell am force-stop`) → 다음 실행 때 볼륨이 복원되는지.
- [ ] B **요청 받지 않기 1시간** → A 홈에 "받지 않는 중" 표시, 울리기 눌러도 B 무음 + 알림 한 줄, A "받지 않고 있어요".
- [ ] B 비행기 모드 → A 울리기 → 30초 뒤 "응답이 없어요".

## 위치
- [ ] 기본 정책(알리고 10초 뒤) → B 카운트다운 → A 지도 카드(핀·주소·오차). B에 "위치를 보냈어요" 알림 + 기록.
- [ ] B 정책 **내가 허용할 때만** → 허용/거절 각각.
- [ ] B 정책 **보내지 않기** → A "위치 공유를 꺼 두었어요".
- [ ] B 위치 권한을 "앱 사용 중에만"으로 → A "가져올 수 없어요", B에 안내 알림.

## 기록·해제
- [ ] 양쪽 기록 화면에 받은/보낸 요청과 결과가 맞게 남는지.
- [ ] 설정 → 연결 해제 → 상대 폰에서도 사라지는지, 이후 요청이 "연결이 끊겼어요".
